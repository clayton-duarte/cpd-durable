# assistant-ui element review

Reviewed on 2026-11-17 after the User selected assistant-ui in place of shadcn AI Elements and requested a full catalogue pass, not a component-for-component substitution.

## Evidence and limits

The [documentation index](https://www.assistant-ui.com/llms.txt) listed **128 element pages**. All 128 pages were retrieved successfully. Every overview and the available integration/anatomy/API section structure was reviewed for applicability. Deeper API and registry-source review concentrated on the selected runtime, primitives and renderers, not every optional backend. This is an applicability review, not a claim that all elements or all example integrations were executed.

Installed React API: `@assistant-ui/react` **0.15.36**, with exact resolved dependencies in the lockfile. Documentation and registry content can evolve independently; the checked-in composition and tests, not a moving website example, define current behavior. The [functional mapping](chat-components.md) owns implementation status and embedding semantics.

Copied registry sources: [Thread](https://r.assistant-ui.com/base/thread.json) and its dependency tree, [CommandPalette](https://r.assistant-ui.com/elements-command-palette.json), [ElicitationForm](https://r.assistant-ui.com/elements-elicitation-form.json), [AgentStatus](https://r.assistant-ui.com/elements-agent-status.json), [ErrorState](https://r.assistant-ui.com/elements-error-state.json) and [Composer](https://r.assistant-ui.com/elements-composer.json), including helpers and supplied shadcn dependencies. Local adaptations preserve literal user whitespace, disallow Markdown images, gate attachment selection on runtime capability, centralize the Markdown stylesheet and satisfy strict TypeScript/lint checks. Runtime and standalone entries have different registry names; a documentation page is not proof that `/base/<name>.json` exists.

Element names below are the page slugs under `https://www.assistant-ui.com/elements/`. Every indexed element is classified once.

## Official elements and durable-host binding

Component priority is **assistant-ui > shadcn; no custom visual components**. The application now mounts the actual registry Thread, not an application-designed primitive composition. Its ComposerExtra slot contains supplied Composer/ComposerToolbar/ComposerMenu, CommandPalette, ElicitationForm, AgentStatus, ErrorState and TooltipIconButton elements. The registry is not a turnkey pi-durable adapter.

- Native Send calls the external-store `onNew` adapter. That adapter restores the detached draft immediately if still empty and clears only the unchanged draft after confirmed host admission. There is no custom submit interception, second draft store or optimistic transcript.
- Native client queue reordering/steering can interrupt a run. pi-durable queues durably and steers at boundaries. The visible queue is projected from `pi.inbox`, with only server-backed withdrawal; no fake edit, reorder or Run now action.
- Native Resume expects a resumable checkpoint for the same message/run. SDK Continue starts a run on unresolved model context. It remains explicitly named Continue rather than pretending to be checkpoint resume or message regeneration.
- ErrorState is used with the real safe-retry callback only. AgentStatus carries honest connection, pending, reset, notice and interruption labels. StoppedRun/ConnectionState defaults are not used to invent unobserved progress or callbacks.
- Unsupported callback/adapters are absent: no edit, regeneration, feedback, attachment, speech, voice, tool execution, new-thread or cloud persistence capability.

Unsupported native attachment and Refresh controls remain visible but disabled. CommandPalette exposes durable busy-input/withdraw/Continue/reset operations; ElicitationForm confirms reset, not general model elicitation. These are selected uses within the broader catalogue groups above, whose other capabilities remain deferred. There are no direct application-level shadcn fallbacks; supplied elements' internal shadcn dependencies are accepted. The former custom chat composition and `@shadcn/react` are removed. See the [feature remap](pi-durable-features.md#assistant-ui-first-feature-remap) for each SDK capability's selected or candidate surface.
